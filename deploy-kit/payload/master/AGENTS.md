# 母版工作区协作约定

这是文档驱动开发框架的模板母版，不是已填写需求的软件产品。先看 README 的当前版本与任务入口，按需读取相关文件。

- 人类决定产品需求；已有授权持续有效，不为格式整理或常规技术选择重复请示。
- 小修改只更新受影响的内容；讨论和只读审阅不要求落档、验收或提交。
- 规则、模板和脚本改动后同步仓库内副本：`python deploy-kit/sync-master.py`。不要从本机旧技能反向覆盖仓库。
- 脚本变更运行 `python -m unittest discover -s tests -v`；发布前运行 `python verify.py --release`，确认版本说明、同步副本和提交状态。
- 00–04 与 START_HERE 是待填写模板。历史草稿与工作日志默认不加载，不把历史命令当成现行授权。
- 正式版本更新维护 VERSION、CHANGELOG 和 releases 对应说明；保留旧提交与标签，不重写既有历史。
